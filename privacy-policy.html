Privacy Policy – Autodarts Camera Settings

Last updated: May 2026

No data collected

The Autodarts Camera Settings browser extension does not collect, transmit, store, or share any personal data or usage information of any kind.

What the extension does

The extension runs exclusively on the Autodarts board's local configuration page (http://<board-ip>:<port>/config). It reads and writes V4L2 camera control values by communicating directly with the board's own REST API on the user's local network. No data leaves the local network.

No third-party services

The extension loads icon font files from the jsDelivr CDN (cdn.jsdelivr.net) solely to display UI icons. No user data is sent to jsDelivr; the request is a standard font/CSS asset fetch with no identifying payload.

No storage

The extension does not use cookies, localStorage, IndexedDB, or any other persistent storage mechanism.

Contact

Questions can be raised via the GitHub issue tracker .
